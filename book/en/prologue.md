# Prologue

Oxpecker starts from a practical engineering question: AI-assisted development can produce code faster, but review, validation, and regression confidence do not automatically become faster.

This project explores whether formal verification can help constrain agent-generated code into forms that are easier to inspect, reproduce, and verify. The Zig implementation is the practice medium; the mission is the review and verification bottleneck.

The English edition will follow the same structure as the Chinese edition. Early pages may be shorter while translation and rewriting continue.
